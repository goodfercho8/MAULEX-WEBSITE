# Sitio web Maulex

Sitio estático listo para GitHub y Vercel. No requiere instalación, compilación, plugins ni dependencias.

## Publicar en Vercel

1. Sube todo el contenido de esta carpeta a la raíz de un repositorio de GitHub.
2. Importa el repositorio en Vercel.
3. En **Framework Preset**, selecciona **Other** si Vercel no lo detecta automáticamente.
4. Deja vacíos los campos de Build Command y Output Directory.
5. Publica el proyecto.

Para revisar el sitio localmente, abre `index.html` en el navegador.
